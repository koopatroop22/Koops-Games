# Browser engine assets

These files are the Stockfish 19 lite, single-threaded WebAssembly build from
the `stockfish` npm package, version 19.0.1. The game loads them in a local web
worker for bot moves and game review.

Stockfish is distributed under GNU GPL v3. See `../Copying.txt` for the license.
Package and build source: https://www.npmjs.com/package/stockfish/v/19.0.1
Engine project: https://github.com/nmrugg/stockfish.js
