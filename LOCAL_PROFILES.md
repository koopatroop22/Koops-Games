# Local player profiles

Koops Games currently stores player profiles and game activity in the browser's local storage. Profiles use a username only; no email address or password is collected.

- Profiles and session history are available only in the same browser and site origin.
- Profiles do not sync between devices or browsers and are not protected from someone with access to the browser.
- Clearing this site's browser data removes local profiles and activity.
- Online search, friends, and account recovery are unavailable in this mode.
- Existing cloud accounts and data are not imported or deleted.

The site is static, so secure online accounts and shared profiles require a trusted backend.
